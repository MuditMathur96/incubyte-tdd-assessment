# Incubyte TDD assessment

## 📦 Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/MuditMathur96/incubyte-tdd-assessment
   ```
2. Install dependencies:
   ```sh
   npm install
   ```

## 🛠️ Usage

### Development

To start the project in development mode:

```sh
npm run dev
```

### Production

To build and run in production mode:

```sh
npm run build
npm start
```

## 🧪 Testing

Run tests using:

```sh
npm test
```
